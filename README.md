# 購物網站 (專賣線上教學課程)

## 前台網頁

1. 課程類別選單,導航列的形式
2. 選擇特定類別進入後,會以九宮格的展示框的形式,每一個課程,有一個展示框,展示框的上半部是圖片,下半部是說明文字,說明文字裡面會有標題跟簡短的內文,另外要有該課程的價格標籤,還有目前招生的人數
3. 會員機制
4. 單獨觀看課程的畫面
5. 付費結帳購買課程的畫面

## 後台網頁

1. 會員機制管理
2. 管理員機制的管理
3. 課程(產品)的上架跟下架的功能
4. 會員購買產品狀況的管理,決定該會員是否有購買特定課程產品


## 資料庫規劃

1. 要用sql server, docker的版本
2. 會員的管理table跟管理者的管理table要分開
3. 課程的table,要把影片的部分,另外存在特定資料夾,刪除特定課程的時候,不要真的刪除,用標記flag的方式就好
4. 會員的管理,要另外有table專門記錄付款歷史,還有當前餘額狀況
